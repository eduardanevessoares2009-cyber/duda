## ✨ Uma descoberta pode virar uma lembrança

Se eu aprender algo importante, posso conversar e escolher guardar. A assistente pode encontrar ligações com outras anotações e perguntar antes de salvar. Se eu disser não, a conversa continua normalmente.

## 🪄 Minhas palavrinhas especiais

| Palavra | O que significa |
|---|---|
| `#DUDA` 🌷 | Reencontrar minhas ideias. |
| `#ACORDAR` 🌱 | Retomar de onde parei. |
| `#CALIBRAR` 🔎 | Conferir se está tudo organizado. |
| `#SALVAR` 📝 | Guardar algo importante que eu escolher. |
| `#CONECTAR` 🔗 | Relacionar ideias e aprendizados. |
| `#KAIZEN` 🌿 | Reconhecer uma pequena melhoria. |
| `#MICHELIN` ⭐ | Aprender, aplicar e conferir. |
| `#PROXIMO` ✨ | Encontrar um próximo passo útil, se eu quiser. |

Também posso usar palavras ligadas à identidade, história, fé e sonhos. Maiúsculas e minúsculas funcionam do mesmo jeito.

## ⭐ Minhas três estrelas

⭐ **Construir:** entender e começar.  
⭐⭐ **Integrar:** colocar em prática e conectar.  
⭐⭐⭐ **Provar:** conferir o que realmente consegui fazer.

Não é competição nem obrigação de ser perfeita.

**🌷 Não preciso lembrar de tudo sozinha. Posso voltar às minhas descobertas quando quiser.**
