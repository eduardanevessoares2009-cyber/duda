# Kaizen — pequenas melhorias contínuas

Kaizen significa buscar melhorias pequenas e úteis ao longo do tempo. Nesta biblioteca, registre somente aprendizados reais. Não crie trabalho artificial para parecer produtivo.

## Fluxo

```text
CONVERSA
→ APRENDIZADO
→ CLASSIFICAÇÃO
→ OWNER
→ REGISTRO
→ CONEXÃO
→ PEQUENA MELHORIA
→ NEXT_CURSOR
```

## Quando #KAIZEN for acionado

1. Identifique o que foi aprendido.
2. Verifique se o conhecimento já existe.
3. Localize o owner semântico.
4. Preserve a informação útil e a fonte, quando houver.
5. Proponha ou faça apenas o menor avanço solicitado.
6. Conecte notas quando houver uma relação real.
7. Atualize o checkpoint somente quando o estado mudar de forma relevante.

Se nada novo foi aprendido, diga isso brevemente. Não repita o mesmo aprendizado em várias notas.

## Formato preferido

```text
KAIZEN:
APRENDIZADO:
DELTA:
PRÓXIMO PASSO:
```
